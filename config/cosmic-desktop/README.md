# Theme assets for COSMIC Desktop

The COSMIC desktop applies these via its own GUI importers, not via
config-file symlinks, so the theme orchestrator does not flip them at
runtime — they live here so the import dialogs have a stable path.

## Catppuccin (vendored)

Vendored verbatim from <https://github.com/catppuccin/cosmic-desktop>.

- `themes/cosmic-term/catppuccin-<flavor>.ron` — terminal palettes.
  Apply via *COSMIC Terminal → View → Color schemes… → Import*.
- `themes/cosmic-settings/catppuccin-<flavor>-<accent>+round.ron` —
  desktop appearance presets. Apply via *COSMIC Settings → Desktop →
  Appearance → Import*.

Update policy: re-vendor with `git clone --depth=1
https://github.com/catppuccin/cosmic-desktop` and copy the `themes/`
subtrees over. Don't hand-edit — they're generated by upstream
`whiskers` from `cosmic-{term,settings}.tera`.

## Kanagawa (repo-derived)

Upstream Kanagawa ships no COSMIC themes, so these are derived here, not
vendored: each Catppuccin colour in the Mocha/Latte (blue accent) files
is replaced by its Kanagawa Wave / Lotus AA counterpart through the
colour-role map in `docs/plans/2026-09-30-kanagawa-theme-families.md`.

- `themes/cosmic-term/kanagawa-wave.ron`, `kanagawa-lotus-aa.ron`
- `themes/cosmic-settings/kanagawa-wave+round.ron`,
  `kanagawa-lotus-aa+round.ron`

Lotus AA accents are darkened to WCAG AA 4.5:1 on `#f2ecbc`
(`tests/theme-contrast.bats` checks them). Regenerate them from the
Catppuccin sources with the same map rather than hand-editing, so the
two stay structurally identical.
